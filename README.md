# Fold Agent

A month-to-month budgeting agent that lives in your browser.

Track every expense, set category limits, and get coaching on pace, leftover cash, and how this month compares to the last.

## Open it

Open `index.html` on your phone or laptop, or use the GitHub Pages deploy from `main`.

## What it does

1. **Home** — leftover cash, income vs spending, wallets, and a live agent tip  
2. **Track** — search and filter every income, expense, and transfer; edit or remove entries  
3. **Agent** — month-to-month insights, daily allowance, projected spend, quick actions  
4. **Plans** — monthly category caps with progress bars  

## Tips

- Use ‹ › or the month chip to jump between months  
- Tap **Load sample month** on Agent to try the coach with demo data  
- Tap **↓** to backup / **↑** to restore a JSON file  

Data stays on your device (`localStorage`). Nothing is uploaded.
